## 🔐 Permissions Justification

**Required Permissions:**

1. **INTERNET** - Required for API calls, trainer search, payments
2. **ACCESS_FINE_LOCATION** - Show nearby trainers on map
3. **ACCESS_COARSE_LOCATION** - Fallback for location services
4. **CAMERA** - Document verification, profile pictures
5. **READ_EXTERNAL_STORAGE** - Profile picture upload
6. **WRITE_EXTERNAL_STORAGE** - Save workout data locally
7. **VIBRATE** - Haptic feedback for interactions
8. **RECEIVE_BOOT_COMPLETED** - Restart notifications after reboot
9. **ACCESS_NETWORK_STATE** - Check connectivity status

**Optional Permissions:**
- **POST_NOTIFICATIONS** - Send workout reminders (Android 13+)
